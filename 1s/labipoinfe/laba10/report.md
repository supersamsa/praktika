## Описание программы

**Реализованный уровень:** 5 (добавлены безусловный и условный переходы)

### Логика работы программы

Программа представляет собой простой эмулятор процессора с архитектурой фон Неймана:

**Ключевые компоненты:**
- **Массив `arr[]`** — моделирует оперативную память, в которой хранятся как команды, так и данные (принцип единого хранилища)
- **Счётчик команд `pc`** — указывает на текущую выполняемую команду в памяти
- **Аккумулятор `acc`** — регистр для хранения промежуточных результатов вычислений

**Поддерживаемые команды:**
- **1** — увеличить значение в аккумуляторе на 1 (без операнда)
- **2** — уменьшить значение в аккумуляторе на 1 (без операнда)
- **3** — прибавить к аккумулятору число из следующей ячейки памяти
- **4** — безусловный переход на указанный адрес
- **5** — условный переход (если аккумулятор равен 0)
- **0** — остановка выполнения программы

**Организация памяти:**
- Команды и данные хранятся в одном массиве `arr[]`
- Для команд с операндами (3, 4, 5) операнд находится в следующей ячейке памяти
- Команды без операндов (1, 2) занимают одну ячейку

**Особенности реализации:**
- Проверка границ памяти при выполнении переходов
- Защита от выхода за пределы массива
- Пошаговый вывод информации о выполняемых командах

### Пример выполнения

Для тестового массива: `{1, 3, 5, 2, 1, 4, 10, 2, 3, 0, 5, 15, 1, 3, 100, 0}`

**Пошаговое выполнение:**
1. `pc=0`: команда 1 → `acc=0+1=1`, `pc=1`
2. `pc=1`: команда 3 → `acc=1+5=6`, `pc=3` (пропуск ячейки с операндом)
3. `pc=3`: команда 2 → `acc=6-1=5`, `pc=4`
4. `pc=4`: команда 1 → `acc=5+1=6`, `pc=5`
5. `pc=5`: команда 4 → переход на адрес 10, `pc=10`
6. `pc=10`: команда 5 → проверка `acc==0` (ложь), `pc=12`
7. `pc=12`: команда 1 → `acc=6+1=7`, `pc=13`
8. `pc=13`: команда 3 → `acc=7+100=107`, `pc=15`
9. `pc=15`: команда 0 → остановка программы

## Листинг программы

```c
#include <stdio.h>

int arr[] = {1, 3, 5, 2, 1, 4, 10, 2, 3, 0, 5, 15, 1, 3, 100, 0};
int len = 16;
int pc = 0; 
int acc = 0;  

int main() {
    printf("Commands: 1-inc, 2-dec, 3-add, 4-jump, 5-jump if zero, 0-stop\n");
    for (int i = 0; i < len; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n\n");

    while (pc < len && arr[pc] != 0) {
        int command = arr[pc];
        
        printf("PC=%2d: command %d -> ", pc, command);
        
        switch (command) {
            case 1: 
                acc += 1;
                pc += 1;
                printf("acc = %d\n", acc);
                break;
                
            case 2:
                acc -= 1;
                pc += 1;
                printf("acc = %d\n", acc);
                break;
                
            case 3:
                acc = acc + arr[pc + 1];
                pc += 2;
                printf("acc = %d (added %d)\n", acc, arr[pc - 1]);
                break;
                
            case 4:
                {
                    int jump = arr[pc + 1];
                    if (jump >= 0 && jump < len) {
                        printf("jump to address %d\n", jump);
                        pc = jump;
                    } else {
                        printf("invalid address %d, skipping\n", jump);
                        pc += 2;
                    }
                }
                break;
                
            case 5:
                {
                    int jump = arr[pc + 1];
                    if (acc == 0) {
                        printf("acc==0, jump to address %d\n", jump);
                        pc = jump;
                    } else {
                        printf("acc!=0, continue (jump to %d ignored)\n", jump);
                        pc += 2;
                    }
                }
                break;
                
            default:
                pc += 1;
                break;
        }
    }
    
    printf("\nFinal acc = %d\n", acc);
    return 0;
}
```
**Комментарий о соответствии принципам архитектуры фон Неймана:**
1. **Принцип единой памяти** — массив `arr[]` содержит как команды, так и данные, что соответствует принципу хранения программ и данных в одной памяти
2. **Принцип последовательного выполнения** — команды выполняются одна за другой, управление потоком осуществляется через счётчик команд `pc`
3. **Принцип адресности** — каждая ячейка памяти имеет свой адрес (индекс в массиве), к которой можно обратиться через счётчик команд
4. **Принцип управления потоком** — наличие команд перехода (4 и 5) позволяет изменять последовательность выполнения команд

### Демонстрация работы переходов
1. **Безусловный переход (команда 4):**
   - В позиции `pc=5` встречается команда 4
   - Из следующей ячейки (`pc+1=6`) читается адрес перехода 10
   - Счётчик команд устанавливается в значение 10
   - Команды между позициями 7 и 9 пропускаются

2. **Условный переход (команда 5):**
   - В позиции `pc=10` встречается команда 5
   - Проверяется условие `acc == 0` (аккумулятор содержит 6, условие ложно)
   - Переход не выполняется, счётчик команд увеличивается на 2
   - Выполнение продолжается с позиции `pc=12`
